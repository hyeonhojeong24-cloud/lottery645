# Lotto 6/45 Web App

A modern Lotto 6/45 simulation web application built with vanilla JavaScript Web Components and modern CSS.

## Features
- **Number Selection:** Manual 1-45 grid selection or random auto-generation.
- **Batch Operations:** "Auto 5 Games" for quick additions.
- **Cart Management:** Manage up to 100 lottery games in a single session.
- **Virtual Points:** Integrated point system (1,000 pts per game).
- **Modern UI:** Clean, responsive design with interactive elements and high-quality visual effects.

## Tech Stack
- HTML5
- CSS3 (Variables, Grid, Flexbox)
- JavaScript (Web Components, ES Modules)
